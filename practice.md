## Lecture 1
In Lecture 1, we learned about the eight JavaScript types (number, string, boolean, object, array, function, null, and undefined) and their various accompanying methods. Null and undefined are two special values: null is used when you explicitly set “no value,” while undefined means a value has not been assigned yet and is the default. Python has only one of these, but JavaScript has both.
